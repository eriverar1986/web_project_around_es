# Tripleten web_project_around_es

Refactorización y uso de clases.

Tecnicas y tecnologías usadas:
HTML y CSS, siguiendo la metodología BEM para nombrar clases. Se usó JavaScript orientado a objetos, creando clases.
Se aplicó el uso de modulos de JavaScript para separar el código en varios archivos, así como herencia de clases.
Se utilizó la creación dinámica de tarjetas con la manipulación del DOM, manejo de eventos click, submit, input, keydown y la validación de formularios con checkValidity, validity.valid y validationMessage.
